## Мета роботи

Набуття практичних навичок з налаштування професійного середовища розробки програмного забезпечення. Оволодіння базовими операціями системи контролю версій Git та платформи GitHub. Ознайомлення з можливостями AI-асистентів кодування для підвищення продуктивності програміста.

## Результати навчання

Після виконання лабораторної роботи студент:

- уміє встановлювати та налаштовувати IDE Visual Studio Code з розширеннями для обраної мови програмування;
- володіє послідовністю операцій Git: `init`, `add`, `commit`, `push`, `branch`, `merge`;
- може створювати та оформлювати pull request на платформі GitHub;
- використовує AI-асистент для генерації фрагментів коду за текстовим описом;
- документує робочий процес із застосуванням формату Markdown.
